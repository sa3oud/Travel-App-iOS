# Chonautia (iOS Archive)

A high-performance iOS application built with **SwiftUI** and **Metal** for real-time visual processing.

## Technical Highlights
- **Metal Framework:** Custom shaders written in MSL (Metal Shading Language) for GPU-accelerated effects.
- **AVFoundation:** Real-time camera feed integration with low-latency processing.
- **Modern Swift:** Fully built using SwiftUI lifecycle and async/await patterns.

## Project Structure
- \`MetalCamera.swift\`: Handles the hardware interface and pixel buffer streaming.
- \`ShaderSource.swift\`: Contains the MSL kernels for visual manipulations.
- \`MetalView.swift\`: The bridge between UIKit/Metal and SwiftUI.
